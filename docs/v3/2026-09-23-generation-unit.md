# V3 GenerationUnit 最小实现

`GenerationUnit` 将一个主检索命中与其已确认的 Evidence Closure 组合为不可变的内存上下文快照。它与 `RetrievalUnit` 分离：前者只负责排序和召回，后者才是回答与核验读取的教材上下文。

- 主对象优先，闭包对象只在剩余字符预算内补入。
- 以 `KnowledgeObject` 覆盖范围去重，避免同一对象既作为闭包又作为下一条主命中重复占用上下文。
- 每次最多组装 3 个单元、默认总预算 12,000 字符。
- 现有 Evidence Ticket、课程权限和引用卡片仍绑定原主命中；闭包不会伪装成独立检索结果。

当前实现覆盖文本对象和已审核关系。图片、表格、公式、页面裁剪及视觉 Token 预算仍待相应对象解析与视觉检索能力到位后扩展。
