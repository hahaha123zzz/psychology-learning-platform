## 1. 总体基线

- 后端已暴露 56 个 HTTP 操作，迁移已到 `0010_rag_v3_objects.py`。
- 后端现有 15 个测试文件、94 个测试函数；其中大部分业务测试依赖 PostgreSQL、Redis 和 MinIO。
- 前端只有首页与 `/student`、`/teacher`、`/admin` 页面骨架，没有实际 API 消费代码。
- Docker 守护进程当前未运行，因此完整 Pytest、Alembic、OpenAPI 漂移和 G0 冒烟尚未重跑。
- V3 仅保留现有基础层，当前收口不继续扩展 V3 解析、索引与模型能力。

## 3. 优先修复顺序

1. 禁止上传时直接发布，学生只读取当前、已解析、已发布且活动的版本。
2. 将质量门禁、教师修正和发布状态形成完整状态机与测试。
3. DOCX 已接入结构解析并明确报告 `layout_bbox_unavailable`；后续接入版面解析服务并用真实教材核对 bbox。
4. 修复学生混合检索与证据二次鉴权。
5. 收口问答、练习、复习和统计链路。
