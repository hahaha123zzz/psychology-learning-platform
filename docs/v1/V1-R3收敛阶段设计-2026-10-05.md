## 2. 目标和退出条件

本阶段的工程目标是让已发布 CourseRelease 的版本身份贯穿学生学习、测评与普通 Tutor 回合，并能按同版教材发布快照检索、留下可审计证据；完成 F 只读 Release 页面、C 学生体验与 G 通用 Lab/资产的隔离验证，随后在静止共同树进行一次统一回归。

达成工程收敛须同时满足：

1. 新建 LearningSession、Assessment Attempt、TeachingActivityRun 和 ChatSession 在有唯一有效指派时固定 `course_release_assignment_id` 与 `course_release_id`；恢复、重试和指派换版不改写历史绑定。无指派兼容路径与多班歧义按合同分别处理，越权及版本不匹配 fail closed。
2. 真实材料发布生成的 PublicationSnapshot 与所选 DomainRelease、成功索引 Job、RetrievalUnit、Embedding 版本一致；Tutor 回合只用固定 Release 允许的快照检索。Claim 保存四态、证据引用和 0/1 次补检索记录；证据不足拒答，不跨课程、班级或版本补检索。
3. F 页面从专属 API 读取两个真实合成 Release，完成 manifest 预览和字段 diff；浏览器网络记录写 API 调用为 0。C 的案例/Growth/Me/Learning-SSE 与 G 的 Mini Lab/TeachingAsset 按各自工程 fixture 验证恢复、失败、键盘和窄屏路径。
4. C/G 会清表的 pytest 只在主窗口新建并核验的空测试库运行，原有浏览器/业务专库继续保留数据。任何数据库、Redis、bucket、物理快照和现存改动均不得为测试而清理。
5. 窗口停止写入后，主窗口在独立 root 环境完成 `upgrade head`、`alembic check`、OpenAPI 两次稳定导出、全后端回归、Ruff、Web test/typecheck/lint/隔离 production build，以及受影响的真实本地浏览器关键路径。失败要修复并重新验证受影响门槛；局部通过不得替代全量结论。

## 3. 跨模块设计合同

### 3.1 不可变运行版本

`CourseReleaseAssignment → CourseRelease → manifest` 是运行版本的入口。创建运行实例时在同一事务选定唯一有效 assignment/release，并将成对 ID 写入运行行；后续读写使用该行的 ID，不查询“当前最新版”替换它。已存在且两列均为 NULL 的历史行保留旧兼容语义，不猜测回填；半空绑定、跨课程 assignment、已撤权用户、资料不在 manifest 和多班无明确选择均拒绝。主窗口统一维护模型、迁移和跨模块测试，B/E/D 仅在各自模块消费合同。

### 3.2 Domain 检索与 Tutor Claim

发布链以真实 API 操作验证：CourseRelease 选择已审核 DomainRelease，教材发布生成 PublicationSnapshot，索引 Job 和 RetrievalUnit 固定相同域版本。A 的知识搜索响应只暴露调用方有权读取的快照身份；学生不得读已撤回、非当前或跨课程快照。B 的活动 ChatSession/SSE turn 根据固定 Release manifest 建立检索 Scope；Claim helper 至多调用一次同 Scope 补检索，并把四态、初检/补检证据 ID、次数和拒答原因持久化。重放同一回合不得重复写业务结果。根跨模块用例必须使用真实发布服务产生的快照，不能仅用直接构造 ORM 快照的 A 专测代替。

### 3.3 前端读取与用户可见结果

F 的 manifest diff 是只读内容比较，页面须明确它不是 Review/Gate 或发布许可；空列表、读取错误和无可比版本均显示真实状态。Branch 学生页归主窗口，创建需真实学生来源，确认合并需 `confirmed=true`、稳定幂等键和说明；跨会话、重复提交与刷新须在隔离浏览器中复核。C 不改 Branch，F 不改共享 API client。E 的测评结果仍遵循服务端 fail-closed；机构成绩可见/保留政策未给出前不扩大默认可见范围。

### 3.4 教师活动、效果与资格

D 已在专库取得 Activity/Intervention 22 项测试通过。主窗口继续核验根路由、OpenAPI 和跨模块运行绑定。干预/Release Impact 只有在来源 Evidence 能追溯 assignment/release、满足独立复测、时间窗和 `n<5` 小样本抑制后才能给出测量结果；此前保持 `not_measured`，不作因果效果声明。G 的作废 Lab 不得继续写入或资格化；TeachingAsset 未知模板按安全纯文本 fallback。

## 5. 不在本阶段伪造的完成项

- `TEXTBOOK/` 的 10 个 OLE `.doc` 是保留来源记录的工程输入，主题为数学，尚无受控本地转换器；不能作为实验心理学教材或固定版面定位验收。最终获准教材、2—3 个实验与 TeachingAsset 正式内容仍需外部输入。
- 机构成绩可见、数据保留/匿名化政策，学生答案用于 AI 的授权及供应商不留存/不训练承诺未给出；`AIGradingSuggestion` 保持 disabled，教材正文和学生答案不外发。
- 真实班级学习效果、生产部署、生产备份/恢复、性能容量和教师预验收属于用户已排除的当前范围。工程 fixture、浏览器脚本和全量测试不能代替这些验收。
