# V1 并行实施窗口提示词

更新时间：2026-10-03

下面的提示词可直接复制到新 Codex 窗口。多个窗口共享当前工作树；每个窗口开始前必须检查 `git status` 与本文第 1 节的当前占用任务，不得覆盖其他窗口的未提交改动。任务以《06-V1总体迁移与实施执行计划》为授权范围，不要反复要求用户确认；遇到真实教材、机构策略或外部服务授权缺口时，安全降级并标清边界。

## 所有窗口共用的开场提示词

```text
继续实施 E:\项目\心里 中已批准的 V1 总体执行计划。请先阅读仓库 AGENTS.md、docs/执行计划/06-V1总体迁移与实施执行计划-2026-10-02.md、docs/v1/implementation-status.md 和与你任务相关的模块/迁移/测试；检查 git status 并保留所有已有改动。默认简体中文，不提交、不重置、不清理无关文件，不把设计目标说成已实现。不要每个小步骤都向用户确认；在被分配的范围内自行实现、测试、同步契约/文档，最后一次性报告。

任务开始前先确认当前文件是否正被另一工作窗口修改。共享模型文件、Alembic 链和同一测试数据库不可并行抢写；如有冲突，选择不重叠子任务或先等待当前拥有者完成。测试涉及 psychology_learning_test 时不要与另一窗口并发跑 pytest，以免截表互相干扰。

完成报告严格区分：已编码、自动测试、本地环境、真实教材/模型、生产验证；提供实际命令与结果。外部模型不得接收真实教材或学生答案，除非项目许可和用户授权已明确；自编 fixture 不能冒称真实教材或科研效度。不要声称整个 V1 已完成，除非逐项通过 P0—P10 和当前验收门槛。
```
