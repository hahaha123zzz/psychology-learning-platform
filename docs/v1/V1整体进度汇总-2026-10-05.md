# V1 整体进度汇总

更新时间：2026-10-05  
范围：截至本次汇总时仓库内可见的 V1 实施状态、验收报告、剩余范围审计、R3 并行状态与交接报告。

## 一句话结论

V1 的后端领域底座、主要学生/教师/管理员路径和若干本地浏览器切片已经落地；当前处于 R3 跨模块收敛阶段，**尚不能称为 V1 整体完成或整体验收通过**。特别是 CourseRelease 固定快照到 Tutor/Branch 的运行链路、静止共同工作树的全量回归、若干业务浏览器闭环，以及真实教材导入/版面定位仍有未关闭项。

不提供一个总百分比：P0—P10 子项的工作量和验收深度差异很大，按“已写代码条数”计算会误导完成度。

## 已经具备的主要能力

- **账号与权限底座：** Cookie 会话、角色/课程 Scope、课程成员与班级/任课关系、审计、幂等与版本冲突处理已有实现；管理员治理已有若干真实隔离浏览器操作证据。
- **课程资料与检索：** 有教材版本、解析/索引任务、知识对象、混合检索、权限前置过滤、证据引用及 PDF 多页定位能力。教师旧教材写入口已默认关闭；替代性的完整内容管理员构建/审校工作台仍未闭环。
- **学生学习与测评：** 有 Tutor/SSE、学习任务与证据、掌握状态、复习、分支会话、正式测评保存/恢复、人工评分、案例工作台、偏好/通知等能力切片。多个故障恢复和双标签测评场景已在隔离环境验证。
- **教学与实验：** 有教师观察、干预/再验证、TeachingAsset 白名单与文本 fallback、Mini Lab 六阶段会话和资格化等工程能力；最终课程实验内容和真实教材资产尚未验收。
- **课程发布与治理：** CourseRelease、Preview/Diff/Gate/Review/Impact/Publisher/Assignment 已有部分真实 API；主窗口已增加发布时对教材版本与 PublicationSnapshot 的精确 pin。Impact 仍可能为 `not_measured`，完整设计/发布工作台和运行期版本固定尚未全部闭环。
- **隐私删除与异步任务：** 有持久删除工作单、状态凭证、任务重试与本地 Worker 故障恢复验证；机构级保留规则、生产备份/索引擦除不在当前已验收范围。
