## 二、当前系统架构

```text
浏览器（Next.js / React）
  ├─ 教师工作台：课程、教材上传、解析审核、索引、发布、学情、题库与测验
  ├─ 学生工作台：已发布教材、教材检索、有据问答、测验、复习、记忆与隐私
  └─ 管理员：健康状态、审计查询
          │ 同源 API 代理 + HttpOnly Cookie
FastAPI 模块化单体（/api/v1）
  ├─ auth / courses / materials / knowledge
  ├─ tutor / assessments / review / memory / analytics / admin
  ├─ OpenAI-compatible generation & embedding adapter
  └─ Celery dispatch / Job recovery / MinIO storage adapter
          │
PostgreSQL + pgvector  Redis  MinIO
  ├─ 业务、版本、对象、任务、索引元数据
  ├─ 会话、队列、Celery broker/result
  └─ 教材原文件、图片对象资产、上传临时分片
```

后端为模块化单体：HTTP 路由在 `server/app/modules/<module>/router.py`，业务逻辑在同模块 `service.py`，公共能力在 `server/app/core/`，ORM 模型在 `server/app/db/models.py`。

## 四、教师端完整业务链路

### 1. 创建课程与成员

教师登录后创建课程、添加学生/助教。服务端通过课程成员关系和角色校验决定访问权；越权用户得到 404。课程修改遵守乐观锁，审计日志记录成员与关键状态变更。

### 2. 上传教材

主路径是可恢复分片上传：

1. 浏览器调用 `POST /courses/{course_id}/upload-sessions` 创建 `UploadSession`。
2. 服务端校验教师权限、文件扩展名/大小/课程配额，创建 MinIO Multipart Upload，并返回分片策略。
3. 浏览器以 8MB 分片向 MinIO 预签名 URL 直传；每段完成后回传 ETag 与大小。
4. 浏览器记录会话 ID；网络中断或切换页面后，重新选择同一文件即可查询已完成分片并续传。
5. 完成时服务端校验连续分片、真实对象长度、SHA-256、重复教材和配额，再创建不可变 `MaterialVersion`。

失败不会静默丢失：会话可取消、过期会清理预留，错误响应包含可操作错误码。单次上传接口仍保留兼容，但不再是主路径。

### 3. 异步解析与审核

教师触发解析后创建 `Job(kind=material_parse)`。Celery Worker 执行下载、解析、质量检查和持久化；Job 保存 `stage`、`progress`、`checkpoint`、心跳、尝试次数、错误和 `retryable`。Worker 崩溃后可通过陈旧任务扫描安全重派发。

V3.3 将 PDF 解析改为页级持久化：每页对象、对象资产元数据、`ParsedPage` 完成记录和 Job checkpoint 一起提交；重试时跳过已完成页面，避免重复对象。重新解析已解析草稿则清除旧页状态、对象和索引，重新开始；已发布版本禁止原地重解析。

解析后的 `KnowledgeObject` 类型包括 `chapter`、`paragraph`、`figure`、`table`、`formula`。教师可查看质量问题并修正对象；修正写入 override/audit 语义，不覆盖原始内容。阻塞问题未处理、索引未就绪时不能发布。

### 4. 构建索引与发布

当前索引主路径只将段落拆为 `text_child` RetrievalUnit：

```text
KnowledgeObject(paragraph)
  → chapter-aware chunk
  → RetrievalUnit(text_child)
  → BM25 / dense index entry
  → 混合检索
```

图片、表格、公式目前只是可定位对象，尚未产生 RetrievalUnit 或视觉索引。索引构建采用原子替换：新向量全部成功后才提交；Embedding 模型版本变化或教师修正都会使旧索引失效。发布时生成 `PublicationSnapshot`，固定绑定教材版本、成功解析任务、成功索引任务与 Embedding 版本；学生只可使用已发布快照。

### 5. 教师端可见功能

- 创建课程、课程成员管理。
- PDF/DOCX 上传及真实分片进度、恢复说明、离页告警。
- 真实解析/索引后台任务、阶段、进度、失败原因和可重试状态。
- 教材工作流：上传 → 解析 → 教师审核 → 构建索引 → 发布。
- 解析审核问题与对象修正。
- 聚合课程学情：参与、测验、掌握、章节、常见错题、复习积压；不暴露私聊正文或学生记忆正文。
- 题库审核发布、出题任务、测验创建和发布。

## 五、学生端功能与实现

学生只能看本课程、已发布且在开放范围内的资源。

- 教材目录/已发布资料：由 PublicationSnapshot 和课程成员权限决定，不显示草稿教材。
- 教材检索：章节、对象类型过滤先于候选和 RRF 排序；文本主路径为 BM25 + Dense（真实 Embedding）或 BM25 + 关键词锚点（本地 hash-v1）。
- 有据问答：SSE 回合输出；检索结果形成证据包和短期 Evidence Ticket；证据不足时拒答或降级。
- AI 教师：服务端状态机管理诊断、提示、练习、总结，不允许模型直接写掌握度或成绩。
- 测验：只发现已发布且开放时间有效的测验；学生作答后服务端评分并返回结果。
- 局部追问：可以创建分支会话，教师/学生确认后再合并主会话。
- 学习记录：学习证据、掌握度、复习任务、分层记忆；支持查看记忆详情和隐私删除请求。

## 六、V3 RAG 与版面解析现状

### 文本检索已验证的部分

OpenStax《Psychology 2e》本地 `hybrid-v4 + hash-v1` 基线：

- Page Recall@5：`1.0`
- Page NDCG@5：`0.826186`
- 教材外问题拒答准确率：`1.0`
- 精确对象 Recall@5：`0.625`
- 首项 bbox IoU：`0.480661`
- 两条独立人工段落金标与原始 bbox 的 IoU：`0.960721`

`hash-v1` 不具有语义向量含义，因此已禁用其伪 dense 通道；它只作为本地 BM25/关键词锚点离线基线。真实外部 Embedding 仍应走最小相似度门槛和 Weighted RRF。

### V3.3 真实 PDF 版面统计

本地 OpenStax PDF（755 页）在 `native-layout-v3.3` 下得到：

| 对象 | 数量 | 具备 bbox |
| --- | ---: | ---: |
| chapter | 16 | 0 |
| paragraph | 11,293 | 11,293 |
| figure | 361 | 361 |
| table | 12 | 12 |
| formula | 0 | 0 |
| 图片资产 | 361 | — |

实现原则：图片仅从 PDF 原生 image block 创建；表格仅在先检测到规则网格、再被 PyMuPDF `find_tables()` 识别时创建；公式只接受独立、短小、包含明确数学运算符且不含普通句式标点的文本块。宁可漏检，不能把段落、图注或猜测结果伪装成对象。

### 绝对不能夸大的结论

- 有 `figure/table/formula` 对象与 bbox，不等于已完成视觉检索。
- `formula=0` 只表示本教材未命中保守规则，不说明教材没有公式。
- 表格目前没有结构化语义/单元格级引用承诺。
- 图片资产目前没有视觉 Embedding、Caption、ColPali/ColQwen 或 Multi-vector 检索。
- OCR、扫描 PDF、复杂版面、MinerU/Docling 仍未接入。

## 七、数据模型要点

- `Material` / `MaterialVersion`：教材逻辑资源与不可变版本。
- `UploadSession` / `UploadPart`：可恢复分片上传会话、Part ETag 与状态。
- `Job`：解析/索引等后台任务，含心跳、尝试次数、检查点和 Worker 后端。
- `ParsedPage`：V3.3 新增页级完成记录，唯一键为教材版本 + 解析器版本 + 页码。
- `KnowledgeObject`：章节、段落、图片、表格、公式等教材对象，记录页码、`bbox`、解析器版本、置信度、审核状态。
- `ObjectAsset`：不可变二进制产物，如图片裁剪/原始对象资产，记录对象键、Hash、尺寸、bbox。
- `ObjectRelation`：`previous`、`next`、`caption_of`、`references` 等对象关系。
- `ObjectRepresentation`：可重建派生表示，不能单独成为教材事实引用。
- `RetrievalUnit` / `RetrievalIndexEntry`：召回与索引层，显式区别于生成上下文。
- `PublicationSnapshot`：一次发布时固定教材、解析、索引、Embedding 版本的不可变快照。
