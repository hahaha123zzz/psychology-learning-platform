# 学生端 V0.9 本地隔离演示手册

本演示只使用本地合成课程与合成 PDF，不读取 `TEXTBOOK/`，不把教材正文、图像或表格发送给任何外部模型。它用于工程 Demo，不代表 V1、真实班级或生产验收。

`TEXTBOOK/` 当前包含 10 份旧格式 `.doc`；本机没有 LibreOffice/Word 转换器，服务端也没有 MS Word parser，现有导入记录均因 renderer 不可用而阻断。该目录内容不在本 Demo 数据中，待本地转换条件就绪后再单独验证。

## 建立或重建合成数据

在仓库根目录的 PowerShell 运行：

```powershell
$env:APP_ENV='test'
$env:TASK_BACKEND='in_process'
$env:MATERIAL_LEGACY_AUTHORING_API_ENABLED='true'
$env:DATABASE_URL='postgresql+asyncpg://psychology:change-me@127.0.0.1:5432/psychology_learning_student_demo_20261005'
$env:REDIS_URL='redis://127.0.0.1:6379/12'
$env:MINIO_BUCKET='student-demo-20261005'
$env:LLM_PROVIDER='internal'
$env:LLM_API_KEY=''
$env:LLM_BASE_URL=''
$env:EMBEDDING_API_KEY=''
$env:EMBEDDING_BASE_URL=''
server\.venv\Scripts\python.exe scripts\seed_student_demo.py
```

脚本只在指定 Demo 数据库中执行 Alembic migration，并通过现有本地材料发布链生成索引、固定来源证据和 practice 测评。它不操作 `.env` 所指向的旧库。

## 启动 API 与 Web

保留上节 PowerShell 环境变量，在第一个终端运行：

```powershell
Set-Location server
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8001
```

在第二个终端（重新设置 Web 专属变量）运行：

```powershell
Set-Location web
$env:PSYCHOLOGY_API_PROXY_TARGET='http://127.0.0.1:8001'
$env:PSYCHOLOGY_NEXT_DIST_DIR='.next-r3-g'
pnpm dev --hostname 127.0.0.1 --port 3001
```

打开 `http://127.0.0.1:3001/login`，使用学生账号登录。停止两个前台进程不会删除 Demo 数据。

## 演示路径

1. Home 恢复当前引导任务。
2. 从课程进入 Learn，搜索 `independent variable`，再问“什么是自变量？”。
3. 等待 Tutor 显示“回答已保存”，打开引用并核对版本、物理页与 bbox 高亮。
4. 进入 Practice，分别提交正确和错误答案；错误答案可在 Review 中选择答案并验证完成。
5. 在 Growth 查看真实 API 汇总，在 Preference 保存回答长度与讲解顺序；刷新后仍应保留。

正式 Assessment 使用独立页面与策略。当前解析/索引尚未建立 Figure/Table 的可验证检索闭包，不能演示图表对象定位或图表专属解释；Reader 对可用的文本引用提供本地页面与坐标锚点。
